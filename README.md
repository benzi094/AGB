# African Global Business (AGB)

Site web de African Global Business (AGB), entreprise multisectorielle basée à Conakry, Guinée : BTP & Construction, Infrastructures, Logistique, Import & Export, Imprimerie et Fournitures.

Basé sur Next.js (App Router), Tailwind CSS et Framer Motion.

## Démarrage

```bash
npm install
npm run dev
```

Le site est disponible sur http://localhost:3000.

## Scripts

- `npm run dev` : serveur de développement
- `npm run build` : build de production
- `npm run start` : serveur de production
- `npm run lint` : analyse ESLint
